# ---------------------------------------------------------------------------
#  BEISPIELBAUM - Charakter 0 (Standard)
#
#  Diese Datei ist NICHT die Wahrheit im Spiel. Sie ist die Vorlage, aus der
#  beim ersten Start einmalig das Asset Assets/Resources/SkillTrees/char_0.asset
#  gebaut wird. Ab da wird im Editor gearbeitet (Tools -> Skilltree -> Editor),
#  und diese Datei bleibt liegen, wie sie ist.
#
#  Neu einlesen (ueberschreibt das Asset):
#    Tools -> Skilltree -> Baum aus Textdatei bauen...
#
#  Die Werte hier sind absichtlich schlicht - es geht darum zu zeigen, was das
#  System kann, nicht um Balance:
#    - je Kategorie ein Startknoten ganz links, von dem die drei Bahnen abgehen.
#      Er steht hier absichtlich NICHT in der Datei: beim Einlesen legt ihn
#      SkillTreeAsset.EnsureStartNodes an, und jeder Knoten ohne req= haengt
#      sich daran. Die Spalten fangen darum bei 1 an.
#    - drei Bahnen je Kategorie, die nach rechts laufen
#    - verschiedene Formen (Kreis, Rechteck, Raute, Sechseck, Stern, Kreuz)
#    - ein Knoten mit ZWEI Vorgaengern (kampf_oben_3 braucht oben UND Mitte)
#    - ein Knoten, der einen Schalter gibt statt nur Werte (das Waffen-Upgrade)
#    - ein Knoten mit mehreren Belohnungen gleichzeitig
#
#  Das Format steht in SkillTreeTextIO.
# ---------------------------------------------------------------------------
